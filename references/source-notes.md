# 来源、提炼与纠偏记录

## 来源边界

本 skill 以用户提供的《德尔菲法专家函询方法与实操(1).docx》为知识底稿。文档正文题名为《德尔菲法专家函询：方法学架构、统计测度体系、赋权算法与国际报告规范全解》；作者、出版信息及再分发授权未提供。

公开仓库只包含新编的操作规则、模板、安装器及说明，不包含原始 Word、其全文抽取、嵌入图片或从中搬用的实证数据表。本 skill 的许可不授予对原文档或其他第三方材料的权利。

提炼时读取了正文与表格。原文大量公式以图片嵌入，纯文本抽取存在公式缺口；未把缺失图片内容猜补为已核验公式。本文所用段号是 `word/document.xml` 的 body 直接子元素序号（含段落/表格），用于审查定位，不是原文作者的章节编号。
