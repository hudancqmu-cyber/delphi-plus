# 统计口径与解释边界

本文件支持写作核查，不预装统计软件，也不宣称对任何未提供的原始数据完成了分析。

## 数据要求与分母

逐条描述可用每条目的频数/原始评分；Kendall’s W 需要专家 × 条目的联合评分或排序矩阵。跨轮个体变化需要可匹配的同一专家和同一条目。AHP 需要相应的成对比较矩阵。

报告实际输入、轮次、评分范围、缺失编码、排除规则、有效样本和软件/版本（实际用过才填）。无评分的“无法判断”不是 0 或中间等级；分母优先用预设规则确定的有效评分数，并另报其人数/比例。缺失是否与专业角色或条目有关也可能影响解释。

| 名称 | 可采用的明确口径 | 写作边界 |
|---|---|---|
| 每轮有效回收率/积极系数 | 本轮有效返回问卷数 ÷ 本轮实际发送问卷数 ×100% | 同时列两个计数，区分邀请同意率、返回率与跨轮留存率；高比例不证明无偏倚 |
| 意见提出率 | 本轮提出至少一条文字意见的专家人数 ÷ 本轮有效参与人数 ×100% | 一人多条仍计一人；不把意见条数混作人数 |
| 条目均数 | 有效评分总和 ÷ 该条目有效 n | 有序量表使用均数应说明约定；结合分布，避免仅凭高均数忽略两极意见 |
| 标准差 s | 样本 SD 常用分母 n−1；说明实际口径 | n不足时不计算；不要混用总体 SD 与样本 SD |
| 满分比 | 最高分人数 ÷ 该条目有效 n | 区分满分比、最高两档支持率与全量表的赞同定义 |
| CV | s ÷ 均数；若用百分数再乘100% | 数值0.25与25%一致；CV依赖均值与量表原点，对有序评分只作约定性描述，非通用共识指标 |
| 中位数/IQR | Q2；IQR = Q3−Q1 | 百分位算法和小样本插值可能不同，应保留实际软件口径 |

表格中 n、单位、百分比精度及脚注应足以还原计算。分母改变时不要沿用首轮专家总数；四舍五入可解释微小合计误差，不能解释明显不一致。

## 专家权威系数 Cr：采用时才报告

常用形式为 `Cr_i = (Ca_i + Cs_i) / 2`，群体系数按研究规定汇总。Ca 的判断依据维度、各档赋值、合成方法，Cs 的等级与赋值都须列明，并给出来源。原始材料同时存在多种赋值方案；它们不是可任意拼接的等价表。

检查 Ca、Cs 是否在声明的范围内、是否同量纲；例如 Cs 最高0.9时，不默认 Cr 能达到1。缺少任一项时不自动填0，也不以他人或群体均值代填。按轮次/层级复测过才分轮/层级报告。

Cr 是特定研究惯例中的自评复合描述，不是所有国际 Delphi 研究的必需指标，也不是结果效度的验证。0.70等经验界线必须注明来源和局限，避免写“Cr高，故结果科学可靠”。

## 固定阈值与界值法

固定阈值为项目设定的绝对门槛。界值法可用当轮所选条目集的分布设定相对门槛，例如：

- 均数界值：`mean(条目均数) − SD(条目均数)`。
- 满分比界值：`mean(条目满分比) − SD(条目满分比)`。
- CV界值：`mean(条目CV) + SD(条目CV)`。

这只是一类已应用规则的形式，不是指南要求。须说明参考条目集（按层级/维度还是合并）、各 SD 的口径、严格/非严格不等号、三项及多维度的 AND/OR、边缘条目处理。阈值随条目集改变，不宜在事后混入固定阈值来“救回”条目，除非如实披露并论证例外。保留必要但未达门槛的条目时，将研究团队的例外决策与专家共识结论分开。

## Kendall’s W：当轮排序协调性

设 m 位专家对 n 个相同条目评分。每位专家在条目间排序，分值相同时赋平均秩；各专家的秩方向必须一致。令条目秩和为 R_j，平均秩和为 `m(n+1)/2`，`S = Σ_j[R_j − m(n+1)/2]^2`。每位专家 i 的并列组校正为 `T_i = Σ_g(t_ig^3 − t_ig)`。常用校正公式：

```text
W = 12S / [m²(n³−n) − m Σ_i T_i]
χ² ≈ m(n−1)W，df = n−1
```

在满足所选检验前提时，第二式常用作渐近检验；小样本、较强 ties 或复杂缺失时依据软件/方法文献选择合适推断，不把近似公式当普适精确检验。全部评分均使分母为0时 W 不可定义，不能报告为0或1。

关键核查：

- 输入矩阵应为相同条目的联合评分，不能拿每条目的5/4/3分人数边际表拼出“原始数据”。并列校正取决于每位专家跨条目的评分组合。
- “未校正W”与“并列校正W”口径分别标明。若用 Friedman 检验推导 W，确认软件 ties、缺失与样本数口径。
- W 体现相对排序的一致程度。所有人给同一条目相近高分或低分，是另一层面的判断；某条目是否达共识还要按预设条目规则评价。
- P 值反映在检验零假设下的证据，不表示一致性幅度；小 P 值不能直接写成“高度一致”。没有通用的 W 高/中/低分级可不加依据套用。
- 比较两轮 W 时先核对专家与条目集是否相同。即使完全相同，W 上升也不是跨轮个体评分稳定的直接检验。
- 实际软件显示 `P=0.000` 通常应按其显示精度报告为 `P<0.001`，不能报告零概率；不要对所有小 P 值都机械套这一界限。

## 可选赋权与特殊模型

**AHP：** 判断矩阵通常满足正值、对角线1、互反性；说明是特征向量法还是几何平均法（后者通常给近似权重），不将二者一概写作完全相同。`CI=(λmax−n)/(n−1)`；`CR=CI/RI`，报告 RI 来源与判断标准。对 n=1、2 或 RI=0 的情况不机械相除。多层全局权重按路径的局部权重连乘，检查同级局部和及最终叶子全局和，区分局部与组合权重。

**RAM/FDM：** 只有在使用时才核查实际手册/论文中的尺度、分位算法、IPRAS 或模糊数映射、参数与边界。不同模糊聚合和去模糊化方式不可混算；不要把示例阈值当作统一标准。不因低分专家与多数意见不同就删除其评分。

如果用户仅提供汇总结果，可以润色其表述和检查能直接验证的算术，明确其余分析尚不能复算，不生成虚假的 W、P、Cr、权重或“软件分析结果”。
