# 方案与报告模板

全部 `【待填写】` 都是待确认事实或设计；模板不含实测数据。只使用与任务有关的部分。

## A. 拟开展研究方案

### 研究目的与方法选择

本研究拟针对【研究对象/使用场景】中的【具体问题】，形成【预期产出及适用范围】。现有证据的主要不足为【有来源支持的缺口】。拟采用【Delphi变体及其选择理由】，通过【程序概述】整合相关参与者的判断。

### 条目准备与组织分工

初始条目拟依据【资料来源、获取方式与截止日期】形成，按【理论或逻辑框架】组织。每项列出名称、定义、适用情境与来源。拟由【角色/人员】完成【材料预审/预试验，如计划进行】。协调组负责【职责】，评分面板负责【职责】，重叠角色与处理措施为【待填写】。

### 面板、招募与参与

面板拟包括【专业/利益相关角色】。纳入条件为【与研究问题有关的操作化标准】，拟通过【抽样与邀请方式】招募【目标人数，需说明依据及失访考虑】。补招、跨轮退出和返回的处理计划为【待填写】。自愿参与、伦理审查和利益冲突管理安排为【根据实际情况填写，不预填审批结论】。

### 函询程序与预设规则

采用【量表范围与全部锚点】分别评价【维度】。无法判断/不适用的记录和统计处理为【待填写】。计划【轮次或实时交互设计及理由】；各轮时间、提醒及反馈方式为【待填写】。

| 决策 | 预设操作定义 | 理由/依据 |
|---|---|---|
| 条目共识 | 支持/反对等级、有效分母、最低有效n、数值边界、必要的分组规则 | 【待填写】 |
| 保留/删除/修订/重评 | 各条件及AND/OR；边缘/冲突与新增条目处理 | 【待填写】 |
| 已达共识条目后续处理 | 锁定或重评及理由 | 【待填写】 |
| 跨轮稳定性（若评价） | 匹配条目/参与者、统计或描述标准 | 【待填写】 |
| 整体终止 | 何时结束；仍未达共识条目的处理 | 【待填写】 |

匿名边界为【谁可识别谁、如何纵向匹配、如何保护反馈摘要】。后续反馈拟包括【群体统计、本人上一轮回答、匿名异议摘要与条目变动】，允许专家保留原判断。

### 分析与记录

按【实际选用的方法】报告各轮参与、条目评分分布、筛选决策及修订轨迹；注明各指标有效 n 和缺失口径。仅在需要时加入 Cr、Kendall’s W 或赋权步骤，并列出相应输入与解释边界。计划与实际执行有偏离时记录变更时点及理由。
